# RESPOSTAS

## Exercício 1

### Pergunta:
Explique porque a sobrescrita de metodos permite comportamentos diferentes para objetos da mesma hierarquia

#### Resposta:
A sobrescrita de metodos permite com que classes que herdam classes que declaram seus metodos possuam um comportamento mais específico relacionado com a função da classe.

Como por exemplo um carro e uma bicicleta, ambos são capazes de mover mas a maneira em que eles fazem isso é diferente, aí que a sobrescrita é mais utilizada
